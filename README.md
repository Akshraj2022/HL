# ?? Hikaru Labs

> **Local-first, Client-side Image Processing SaaS.**

Hikaru Labs is a powerful, privacy-first image processing suite built directly into the browser. Utilizing modern web technologies like Web Workers and HTML5 Canvas, all operations are performed locally on your device—ensuring zero data leaves your computer without your explicit consent. 

Experience lightning-fast conversions, manipulations, and optimizations without relying on cloud servers for heavy lifting.

---

## ? Features

- **?? Local-First Processing:** Everything runs securely in your browser. No uploads, no waiting.
- **? Web Worker Accelerated:** Multi-threaded engines utilize maximum hardware potential without blocking the UI.
- **??? Smart Compress:** Fine-tune image quality or compress directly to an exact target file size.
- **?? Format Converter:** Effortlessly switch between JPEG, PNG, WEBP, and more.
- **?? Resize & Crop:** Precise pixel manipulations and smart cropping.
- **?? Image Adjustments:** Rotate, blur, apply custom watermarks, or experiment with film filters.
- **??? Exif Scrubbing:** Strip hidden metadata and EXIF data to protect your privacy.
- **?? Passport Tools:** Quickly format and align portraits for official documentation.

## ?? Getting Started

Simply open `browse.html` in any modern web browser to access the tool suite.

1. Create an account or log in (Powered by Firebase Auth).
2. Choose a tool from the sidebar.
3. Drag & drop your images or ZIP archives.
4. Export the processed results instantly.
